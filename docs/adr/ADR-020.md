# ADR-020 — Web stack e repository
Stato: Accettata dall'utente il 2026-10-05 (“procediamo con questa versione”).

## Decisione
Web responsive; TypeScript; React + Vite; backend Node.js + NestJS; PostgreSQL; IndexedDB per cache/coda offline. Una repository con docs/, apps/web/ e apps/api/. Backend in apps/api/src/modules/ con i cinque moduli della baseline.

## Motivazione
Un solo linguaggio applicativo, convenzioni esplicite per modularità e persistenza transazionale. L'utente non ha esperienza pregressa né vincoli tecnologici e preferisce tecnologie diffuse con complessità contenuta.

## Conseguenze
Offline e invarianti restano responsabilità progettuali. Repository interni ai moduli; nessun package condiviso preventivo. Auth, librerie database/test e versioni sono scelte successive. L'accettazione dello stack non autorizza implicitamente nuove regole di prodotto.
